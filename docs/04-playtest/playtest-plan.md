# 사람 플레이 계획 (2판, 2026-10-02)

> 1판(일생·결말 5종·맡기기·그리드 크기 비교 기준)은 구조가 바뀌어 폐기. 기준 문서 `00-current-design.md`, 스펙 §5.19~§5.23.
> 대상 빌드: **M9 완료 빌드** (임시 스킨). 폰 브라우저(LAN 또는 비공개 배포), `?playtest=1`.

## 1. 무엇을 확인하나 (가설)
| # | 가설 | 어떻게 보나 |
|---|---|---|
| H1 | **머지가 재밌다** — 이야기 우물에서 합치는 손맛, 자기 체인 → 스킬 게이지가 이해된다 | 관찰(손이 우물에 가 있는 시간), 질문 Q1·Q2 |
| H2 | **낮(씨앗 찾아 돌아오기) / 밤(씨앗 지키기)** 두 맛이 구분되고 둘 다 긴장된다 | 낮·밤 실패 비율(metrics), Q3 |
| H3 | **막히면 키워서 넘는다**가 답답하지 않다 — 다음 날 잉크로 레벨 올려 넘기 | 세션 사이 잉크 붓기 사용, 연속 실패 수, Q4 |
| H4 | **편성 고민이 생긴다** — 적성·인연·배우는 스킬(다시 읽기에서 4명) | 편성 화면 연 횟수, 다시 읽기 편성 바꿈, Q5 |
| H5 | **이야기가 읽힌다** — 장면 카드·이야기 한 장·이야기책이 다음 장을 궁금하게 한다 | Q6, 이야기책 연 횟수 |
| H6 | **조작이 버겁지 않다** — 클릭 0 흐름, 자동 스킬, 우물 헤엄 | 헛손질(놓친 드래그), Q7 |

## 2. 진행
- **트랙 A — 실제 흐름 (2~3일):** 하루 2~3번(세션) 원하는 만큼. 1챕터 완성까지 또는 3일. 그다음 다시 읽기로 흠집 없음 도전 1회 이상.
- **트랙 B — 집중 30분:** 처음 보는 사람 1~3명. 설명 없이 1-1~1-4. 옆에서 관찰만, 막힌 곳 메모.
- 디버그 금지(트랙 A). 시간 감기 없음 — 잉크는 실제 시간으로.

## 3. 매 세션 끝 질문 (5초, `?playtest=1` 3장마다 + 챕터 완성)
- Q1 이번 판, 합치는 게 즐거웠나? (좋았다 / 그저 / 별로)
- Q2 다시 하고 싶나? (하고 싶다 / 지쳤다)

## 4. 끝나고 인터뷰 (5분)
- Q3 낮과 밤 중 어느 쪽이 더 재밌었나? 왜?
- Q4 막혔을 때 어떤 기분이었나? 다음 날 들어와서 레벨 올리는 게 자연스러웠나?
- Q5 편성을 바꿔 본 적 있나? 무엇 때문에? (다시 읽기에서 오누이·인연)
- Q6 이야기가 기억에 남나? 다음 이야기(2챕터)가 궁금한가?
- Q7 가장 귀찮았던 조작은? 손이 바빴던 순간은?
- Q8 이 게임을 한 문장으로 설명하면?

## 5. metrics에서 볼 것 (`npm run metrics`)
- 스테이지별 시도 수·낮/밤 실패·돌아오는 길 실패, 세션 수, 세션 사이 잉크 사용
- 머지 수(전투 중/밖), 스킬 발동(자동/수동), 5단계 수, 버려진 조각
- 편성 화면 연 횟수·바꾼 횟수, 재시작(편성 변경) 수
- 이야기책 연 횟수, 다시 읽기 횟수, 흠집 없음 장 수
- 플레이 시간 / 세션 길이

## 6. 판정 (플레이 뒤 결정할 것)
- H1·H2 중 하나라도 "별로"가 많으면 → 본 개발 전에 그 부분 다시 설계.
- H3 "답답" → 성장 속도(잉크·경험치)·1-7~1-9 난도 낮춤.
- H4 고민 없음 → 적성 배율·인연 효과 키움, 조합법 영웅 추가(D-068 보류 해제).
- 미결정 B 목록(우물 상한·실패 경험치·잉크 속도·릴레이 교대·체인 수)을 이 결과로 정리.
