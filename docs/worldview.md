# Happy And Unhappy — 세계관 초안 (2026-09-29)

## 코어 판타지
> **Happy는 행복을 방해하는 공격을 막고, Unhappy는 심연으로 내려가 불행을 정화한다. 둘이 합쳐질 때 아이는 비로소 행복해진다.**

- 양의 세계: 행복을 방해하는 공격을 막는다 (Happy, 머지 디펜스)
- 음의 세계: 막지 못한 상처와 오래된 불행한 기억이 가라앉은 심연. 내려가서 정화한다 (Unhappy, 방치형)
- 합쳐짐: 정화된 기억이 양의 세계로 올라와 머지 조각이 되고, Happy가 그것을 합쳐 큰 추억을 만든다 → "지켜낸 행복 + 정화된 불행 = 진짜 행복"
- 정화 연출 규칙: 불행을 없애는 것이 아니라 되돌려 놓는 것. 그림자가 걷히면 안에 있던 기억이 빛 조각으로 드러난다.

## 확정
- 세계관 방향: **한 아이의 마음**
- 마음의 주인: **한 아이** (플레이어가 아님). 아이는 직접 조작하는 용사가 아니다.
- 플레이어의 역할: 아이의 마음속 **Happy와 Unhappy를 키운다.**
- 게임의 결과: **Happy·Unhappy를 어떻게 키웠느냐에 따라 아이가 어떤 어른이 되는지 결정된다** (다중 엔딩).
- 양의 세계 장르: **머지 디펜스** (Happy가 수호. 작은 기쁨을 합쳐 큰 추억으로. 음에서 정화한 기억이 머지 조각으로 들어옴)
- 음의 세계 장르: **방치형 오펜스** (Unhappy가 기억의 심연을 한 층씩 내려가며 정화)
- 톤: **동화 톤의 따뜻한 게임**
- 개념: 행복/불행 유지. 핵심 규칙 = "불행을 외면하면 역류한다"
- 아트: **도트(픽셀) 그래픽**
- 플랫폼: **모바일**
- 개발 전략: **프로토타입(Phaser 3, 버리는 코드)으로 재미 검증 → 재미 확인 시 Godot 4.7로 본 개발**

## 톤 가이드 (따뜻한 동화)
- 게임 전체는 따뜻하고 다정하다. 불행을 무섭게 그리지 않는다.
- 불행한 기억·몬스터는 "물리칠 적"이 아니라 "돌봐주고 안아줄 존재"로 표현한다. 정화 = 위로.
- 역류·가짜 엔딩의 긴장감은 공포가 아니라 쓸쓸함으로 전달한다.
- 가장 나쁜 결말에도 희망을 남긴다.
- 한 줄 요약: "불행을 없는 척하지 않고, 따뜻하게 안아주는 동화."

## 핵심 전제
- 무대는 한 아이의 마음속이다. 아이는 챕터(나이)마다 자란다 (예: 5살 → 8살 → 12살 → ... → 어른).
- 양의 세계(의식): 행복한 기억이 모인 곳. 일상의 걱정이 몬스터가 되어 몰려오고, Happy가 머지 디펜스로 막는다.
- 음의 세계(무의식): 막지 못한 상처와 오래된 불행한 기억이 가라앉은 심연. Unhappy가 내려가 정화한다(방치형).
- 메시지: 행복은 불행을 지워서가 아니라 소화해서 지켜진다.

## 캐릭터
- 아이: 마음의 주인. 플레이어가 직접 조작하지 않는다. Happy·Unhappy의 상태에 따라 반응하고 자란다.
- Happy: 양의 세계를 지키는 수호자 (모두가 원하는 모습)
- Unhappy: 음의 세계로 내려가 정화하는 탐험자 (아무도 원하지 않지만 실제로 고된 일을 하는 쪽). 악역이 아님.
- 엔딩: 둘은 아이의 두 면. "Happy가 웃을 수 있었던 건 Unhappy 덕분" → 제목의 And에 의미.
- (안) Happy·Unhappy를 동물형 캐릭터로 디자인 → 귀여움 확보 + 인사이드 아웃과 시각적 차별화.

## 성장치 정의 (안) — 결말 판정의 입력값
- Happy 성장치: 머지로 만든 최고 추억 등급 + 방어한 웨이브 수 + 누적 기쁨
- Unhappy 성장치: 정화한 기억 수 + 도달한 심연 층 + 해소한 그림자량
- 설계 의도: 머지 디펜스는 수동이라 플레이 시간이 자연스럽게 Happy에 쏠림 → 기본값이 "웃는 가면" 쪽으로 기울어짐 = 게임의 역설을 시스템으로 구현.
- 단, Unhappy는 방치형이므로 적은 조작으로도 충분히 키울 수 있어야 함 (접속 시 짧은 관리만으로 균형 가능하게).

## 결말: 아이가 어떤 어른이 되는가 (안)
Happy·Unhappy 성장 균형으로 판정 (2×2 + 히든)

| Happy | Unhappy | 어른 | 비고 |
|---|---|---|---|
| 강 | 약 | 웃는 가면의 어른 | 가짜 행복 엔딩. 늘 웃지만 공허 |
| 약 | 강 | 조용한 어른 | 아픔을 알지만 웃는 법을 잊음 |
| 약 | 약 | 비 오는 어른 | 쓸쓸하지만 우산을 건네는 누군가가 있다 |
| 강 | 강 | 단단한 어른 | 진짜 엔딩. 슬픔을 안고도 웃을 수 있음 |
| 균형 + 조건 | | (히든) Happy와 Unhappy의 화해 | 둘이 하나가 되는 장면 |

## 타이틀 연출
핵심: **Unhappy라는 단어 안에 Happy가 들어 있다.** 로고에서 암시하고, 엔딩에서 회수한다.

### 1. 수면 반사 로고 (타이틀 화면)
- 세로 화면의 수면 구조를 로고에 그대로 적용.
- 수면 위: "HAPPY" (따뜻한 팔레트) / 수면에 비친 반사: "UNHAPPY" (차가운 팔레트).
- 의미: Happy를 비추면 Unhappy가 된다 = 둘은 같은 존재. 첫 화면부터 엔딩의 반전을 암시.

### 2. 결말별 엔딩 제목
엔딩 크레딧의 제목이 아이가 어떤 어른이 되었는지를 보여준다. 설명 없이 제목만으로 메시지 전달.

| 결말 | 엔딩 제목 |
|---|---|
| 웃는 가면의 어른 | **Happy** — Unhappy 글자가 사라진 제목. 완벽하지만 비어 있음 |
| 조용한 어른 | **Unhappy** |
| 비 오는 어른 | **Happy And Unhappy** — 글자가 빗물에 번짐 |
| 단단한 어른 | **Happy And Unhappy** — 그대로. And에만 빛이 들어옴 |
| (히든) 화해 | Unhappy 안의 "happy"와 Happy가 겹쳐 **(Un)Happy** 하나가 됨. 마지막 대사: "불행 속에도 행복이 들어 있었어." |

### 현지화 주의
- 이 말장난은 영어에서만 성립 (한국어 "행복/불행"은 글자를 공유하지 않음).
- 방침(안): 로고는 전 세계 공통 영어 "Happy And Unhappy" 유지, 반전은 시각 연출로 전달.
- 필요 시 한국어판 부제 별도 (예: "해피 앤 언해피: 마음의 수면").

## 인생 이벤트 (안)
- 챕터 사이에 아이의 인생 이벤트 발생 (친구와 싸운 날, 전학, 동생이 태어남 ...).
- 플레이어는 아이 대신 선택하는 게 아니라 **그 일을 Happy와 Unhappy 중 누가 맡을지** 정한다.
  - Happy가 맡음(웃어넘김 = 회피): 기쁨 +, 그림자 누적
  - Unhappy가 맡음(마주함 = 직면): 기쁨 −, 음의 세계에 정화 가능한 기억 생성
- 분기는 트리가 아니라 누적 변수. 이벤트·수치는 JSON 데이터로 분리.

## 두 세계의 연결
| 방향 | 시스템 | 세계관 해석 |
|---|---|---|
| 양 → 음 | 머지 디펜스에서 놓친 몬스터가 음의 세계에 가라앉아 강한 적이 된다 | 제때 다루지 못한 스트레스가 상처로 남는다 |
| 음 → 양 | 정화한 기억이 양의 세계 머지 조각이 된다 | 극복한 아픔이 마음을 단단하게 만든다 |
| 음 방치 → 양 | 그림자 누적 → 역류 보스 웨이브 | 외면한 감정은 더 크게 돌아온다 |
| 전역 | 마음 날씨(맑음 ~ 폭우) 게이지 | 전체 기분 상태 |

## 콘텐츠 축
- 양의 세계 웨이브: 아이의 일상 걱정 (받아쓰기 시험, 주사 맞는 날, 발표 시간, 편식 반찬)
- 음의 세계 스테이지: 상징적 기억 장면 (놓쳐버린 풍선, 혼자 남은 운동장, 동생에게 뺏긴 자리, 함께 자란 강아지와의 이별)
- 몬스터: 의인화한 감정(불안, 후회, 질투, 외로움 ...) — 귀엽고 안쓰러운 모습
- 재화: 기쁨(양), 그림자 조각(음), 정화된 기억(결합 재화 = 머지 조각)
- 소재 수위: 학대·이혼·죽음 등 무거운 주제는 제외하거나 상징적으로만 다룬다 (기준 확정 필요).
- 타깃: 아이가 주인공이지만 아이용 게임이 아님. 성인 대상.

## BM 원칙
- 정화 가속·역류 방지·성장 가속 판매 금지 ("아이의 슬픔/성장을 돈으로 산다" 인상 방지).
- 코스메틱 중심 (Happy·Unhappy 스킨, 마음 정원 꾸미기 등).

## 기술 전략 메모
- 프로토타입: Phaser 3 — 빠른 검증용, 본 개발로 이어가지 않는 전제.
- 본 개발: Godot 4.7 — 네이티브 실행, 2D 조명/셰이더. (착수 시 stable 여부·Android export 상태 확인)
- (참고) Phaser 최신은 4.x(2026-04 4.1.0).
- 이관 대상은 **규칙 문서 + 밸런스 수치(JSON)**. 수치 하드코딩 금지.
- 프로토타입 타임박스 2~4주: 머지 그리드(최소 3×3, 조각 3단계, 몬스터 1종), 음 방치 진행(숫자 수준), 두 세계 재화 연결, 역류 1회, 인생 이벤트 1개 + 결말 판정 로직. 도트 에셋·사운드·UI 꾸미기 제외.
- 프로토타입의 검증 대상은 머지 자체가 아니라 "음에서 정화한 기억 → 양의 머지 조각" 연결 루프.
- 재미 판정 기준(예): 3일 연속 스스로 켜게 되는가 / 음의 세계를 확인하러 내려가고 싶은가 / 역류가 짜증이 아니라 긴장감인가.

## 모바일·도트 화면 아이디어
- 세로 화면을 수면으로 나눔: 위 = 양의 세계(머지 그리드), 아래 = 수면에 비친 음의 세계(Unhappy 방치 진행).
- 팔레트 스왑: 양(따뜻·밝음) / 음(차갑·채도 낮음). 마음 날씨도 팔레트 변화로 표현.

## 차별화 메모
- 아이의 마음 + 의인화 감정 → 인사이드 아웃과 겹칠 위험 큼. 차별점: 두 세계 공간 구조 + 억압/역류 시스템, 주인공은 감정이 아니라 두 개의 자아, 한 시기가 아닌 어른이 되기까지의 긴 성장, 결말이 "어떤 어른이 되는가".

## 미정 / 미해결
- 회차 구조: 어른이 되면 결말 → 다음 회차(새 아이 / 이어받는 요소) vs 챕터 되감기
- "방치"의 정의: 음의 세계 자동 진행과 "외면하면 역류" 규칙의 충돌 해소 (안: 전투는 자동, 층 선택·정화 확정·강화는 수동 → 미루면 그림자 누적. 프로토타입 스펙에 이 안으로 반영)
- 한 회차 길이 (머지·방치의 장기 성장 vs 아이 성장의 끝)
- 성장치 정의·결말 판정 임계값 확정
