# 소재 수위 기준 (2026-10-01, D-031)

> 무거운 일을 귀여운 그림체로 다가가기 쉽게 만드는 것은 이 게임의 강점이다. 다만 **어떤 무거움이냐**에 따라 "보듬기"가 될 수도, "소비"가 될 수도 있다. 이 문서는 그 선을 정한다.
> 관련: 세계관 `worldview.md` (톤 가이드, D-004), 결정 기록 D-031.

## 1. 다루지 않는다
- **현대사·실제 역사적 사건** (전쟁, 학살, 재난, 독재, 특정 정치 사건) — 사건 자체도, 배경 암시로도 쓰지 않는다.
- 실제 인물·실제 집단을 연상시키는 걱정·보스·이벤트.
- 학대, 자해, 성적 소재.

- **지금도 믿는 종교의 신** (예: 힌두교 신들) — 설화 여행(D-040)에서 다루지 않는다. 고대 신앙 신화(그리스·로마, 북유럽, 이집트 등) 위주.
- 현대 각색물(마블·영화·다른 게임)의 신·괴물 해석과 디자인.

## 2. 조심해서 다룬다 (개인의 무거운 일)
- 반려동물·조부모와의 이별, 이사·전학, 동생이 태어나 서운함, 가족이 아픈 날, 부모의 다툼, 친구와의 싸움.
- 원칙
  1. **걱정은 아이 안의 감정이다.** 실제 사람이나 집단을 상징하지 않는다.
  2. **무거운 일은 적·난이도·점수로 만들지 않는다.** 전투(걱정 웨이브)보다 **이정표 선택과 그림일기**에서 다룬다 — 마주할지 웃어넘길지를 고르는 장면이 무게를 담는다.
  3. **정화는 물리침이 아니라 안아줌·되돌려 놓음**으로 표현한다 (D-007).
  4. 죽음·이별은 **상징적으로만** (D-011): 직접 묘사 대신 빈자리, 남은 물건, 하늘의 별 같은 이미지.
  5. 아이 눈높이: 아이가 이해하는 만큼만 보여주고, 어른의 사정은 설명하지 않는다.

## 3. 편하게 다룬다
- 평범한 하루의 작은 걱정 (받아쓰기, 주사, 발표, 편식), 작은 기쁨 (좋아하는 반찬, 생일, 첫눈).
- 퍼블릭 도메인 동화·설화의 두려움(호랑이, 늑대 등)을 **원전 기준으로 부드럽게 다시 쓴 것** — 원작의 잔혹한 대목(잡아먹힘 등)은 상징으로 바꾼다. 현대 각색본(특정 번역·삽화·디즈니 등)의 설정·디자인은 쓰지 않는다.

## 4. 점검 질문 (이벤트·걱정·문장을 쓸 때)
- 이걸 겪은 실제 사람이 보면 가볍게 다뤘다고 느낄까?
- 이 무거운 일이 "막으면 기쁨 +"로 계산되고 있지 않은가?
- 그림일기 문장이 아이의 말투인가, 어른의 해설인가?
