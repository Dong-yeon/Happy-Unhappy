# Happy And Unhappy — 세계관 초안 (2026-09-29)

## 코어 판타지
> **Happy는 행복을 방해하는 공격을 막고, Unhappy는 심연으로 내려가 불행을 정화한다. 둘이 합쳐질 때 아이는 비로소 행복해진다.**

- 양의 세계: 행복을 방해하는 공격을 막는다 (Happy, 방어 레인)
- 음의 세계: 막지 못한 상처와 오래된 불행한 기억이 가라앉은 심연. 내려가서 정화한다 (Unhappy, 심연 레인)
- 합쳐짐: 머지 그리드에서 합친 추억을 Happy 쪽(지키기) 또는 Unhappy 쪽(정화하기)으로 보낸다. 정화된 기억은 더 큰 조각이 되어 그리드로 돌아오고, 그것을 합쳐 더 큰 추억을 만든다 → "지켜낸 행복 + 정화된 불행 = 진짜 행복"
- 정화 연출 규칙: 불행을 없애는 것이 아니라 되돌려 놓는 것. 그림자가 걷히면 안에 있던 기억이 빛 조각으로 드러난다.

## 낮과 밤 (2026-10-01 확정, D-027)

> **해가 뜨고 질 때까지 Happy가 걱정을 막고, 달이 뜨고 질 때까지 Unhappy가 꿈속으로 내려가 낮의 걱정과 힘듦을 정화한다.**

```
┌──────────── HUD ────────────┐
│ 하늘: ☀ 이 왼쪽에서 떠서 오른쪽으로 진다 (밤: 🌙) │
├─────────────────────────────┤
│ 낮  Happy┃추억 ← ← ← ← 걱정이 밀려옴        │
│ 밤  Unhappy → 추억 → → → ▓그림자 벽▓       │
├──── ☀ 창문 ──────── ◐ 손거울 ────┤
│        머지 그리드 (엄지 영역)            │
└─────────────────────────────┘
```
- **두 세계가 시간으로 나뉜다.** 낮 = 의식(양·해·창문), 밤 = 무의식(음·달·손거울). 같은 가로 레인에서 낮에는 걱정이 **밀려오고**, 밤에는 추억이 **전진한다** — 거울 반사 구조가 시간축으로 옮겨갔다.
- **낮의 손거울 = 맡기기.** 낮에 손거울에 놓은 추억은 바로 싸우지 않고 밤까지 맡겨둔다. 해가 지면 맡겨둔 추억들이 함께 꿈속으로 내려간다. → 낮 내내 "지금 지키는 데 쓸까, 밤을 위해 맡길까"를 고른다.
- **인과:** 낮에 막지 못한 걱정은 그날 밤 그림자 벽을 단단하게 만든다. 낮에 번 기쁨(밝은 기운)으로 밤에도 추억을 부른다. 밤에 정화한 기억은 더 큰 조각으로 돌아와 다음 날 아침을 지킨다.
- **외면:** 밤에 아무도 내려가지 않으면 Unhappy는 꿈속에서 멈추고 그림자가 쌓인다 → 다음 낮에 역류.
- 아래 "핵심 조작"·"소환 후 레인 규칙"의 좌우 분할·동시 진행 서술은 이 섹션 이전 기록이다. 규칙(지키다 쓰러지면 사라짐 / 뚫으면 성장해 돌아옴)은 그대로 유효하다.

## 핵심 조작: 머지 그리드 + 두 통로 소환

```
┌──────────────── HUD ────────────────┐
│  양: 방어 레인 (따뜻) ┃ 음: 심연 레인 (차가움) │
│                      ┃   ▓▓ 그림자 벽 ▓▓    │
│   걱정 ↓ 내려옴       ┃   ↑ 추억이 전진       │
│                      ┃   (거울 속 깊이)      │
│  ── Happy 방어선 ──  ┃      Unhappy         │
├────────────── 거울 틀 ──────────────┤
│   머지 그리드 (하단, 엄지 영역)  ← 플레이어가 직접 하는 건 여기뿐 │
│   ☀ 창문 포탈 = Happy에게   ◐ 손거울 포탈 = Unhappy에게 │
└─────────────────────────────────────┘
```
- **화면 구조: 가운데 세로 거울을 경계로 좌우 분할** (2026-09-30 변경, D-017). 왼쪽 = 현실의 마음(Happy, 양), 오른쪽 = 거울에 비친 마음(Unhappy, 음).
- 그리드를 기준으로 왼쪽은 걱정이 **다가오고**, 오른쪽은 추억이 **멀어져 거울 속으로 들어간다** → 방어/공격의 반전이 한 화면에 드러남.
- **포탈 소환 (D-018):** 거울 받침 가운데의 두 포탈 — ☀ 창문(Happy에게) / ◐ 손거울(Unhappy에게) — 로 조각을 드래그해 보낸다. Happy와 Unhappy는 각자의 포탈 앞에 선다.
- **연결감:** 소환·기쁨·귀환·가라앉음이 포탈과 거울을 통과해 흐르는 모습으로 보여, 그리드와 두 세계가 하나의 마음으로 이어져 보인다.

- 플레이어의 조작: 조각 생성 → 머지 → **어느 통로로 보낼지** 선택 (드래그로 왼쪽/오른쪽 레인에 놓기. 드롭 판정은 레인 영역 전체).
- 보낸 조각은 그리드에서 소모되고, 해당 레인에 유닛(추억)으로 소환된다. 전투는 양쪽 모두 자동.
- 핵심 긴장 두 가지
  1. **지금 보낼까, 더 합칠까**: 합칠수록 강한 추억이지만 그동안 레인이 비어 있다.
  2. **Happy에게 보낼까, Unhappy에게 보낼까**: Happy 쪽 = 당장의 안전(행복 지키기), Unhappy 쪽 = 늦게 돌아오는 보상(불행 정화). Happy에게만 보내면 음이 방치되어 그림자가 쌓인다 → 게임의 역설이 한 번의 선택으로 표현됨.
- 보상 비대칭(설계 원칙): Happy에게 보내면 효과가 즉시, Unhappy에게 보내면 효과가 지연되지만 더 크다 (정화 성공 → 더 높은 등급 조각이 그리드로 돌아옴).
- 레인 구조: 양은 막는 쪽, 음은 뚫는 쪽. **같은 레인 전투 코드를 방향만 뒤집어 공유** (거울 반사 구조와 일치).
- 유닛 아트: 같은 추억 유닛을 위에서는 따뜻한 팔레트, 아래에서는 차가운 팔레트로 표시 → 같은 기억이 세계에 따라 다르게 보임.
- Happy·Unhappy의 위치: Happy는 방어 레인의 거점(수호자), Unhappy는 심연 레인의 선두(탐험자). 소환된 추억은 각각의 편에 합류한다.
- 보류: 음의 "기억 덱 편성"(스톤에이지 키우기식)은 채택하지 않음. 본 개발에서 장기 성장 레이어가 필요할 때 재검토.

## 추억 체인과 영웅 소환 (2026-09-30 확정)

> **2026-10-01 자라는 날 (D-030):** 아이가 자라는 날(5일·10일·일생 끝), 그동안 만든 **전설 추억은 모두 양분이 되어** 아이 안에 특성과 성장으로 남는다. 행복한 추억(낮을 지키며 쌓은)과 정화된 추억(밤에 안아준)은 같은 무게로 소중하며, 둘이 짝지어지면 **기억**이 된다. 결말은 얼마나 많은 추억을, 어떤 비율로 양분으로 줬는지로 정해진다.
>
> **2026-10-01 개편 (D-029):** 영웅은 **죽지 않고 다쳐서 쉰다** (낮에 다치면 그날 밤, 밤에 다치면 다음 날 낮을 쉰다). 밤에 정화하면 **빛나는 영웅**이 되어 돌아오고, 빛나는 영웅과 다른 추억을 합쳐 **전설 추억**을 만든다 (조합표 — "혼자가 아닌 밤", "공원 산책", "포근한 낮잠"). 영웅을 쓰는 길은 **지키기(낮) · 정화하기(밤) · 조합하기(그리드)** 세 가지. 와일드카드는 심연 **10층마다 오는 보스 층**을 넘으면 얻는다. 아래의 "3단계 정화 → 와일드카드"는 이 개편 이전 기록.

기억의 조각이 쌓여 그 기억과 관련된 영웅이 소환된다. 예: "강아지와 뛰어놀던 추억" 조각을 합치면 강아지 영웅을 소환할 수 있다.

### 체인 구조: 머지 체인의 정점 = 영웅
```
[강아지 체인]
 1단계  강아지 발자국      → 소환 시 작은 추억 정령 (공용 유닛)
 2단계  공놀이한 오후      → 소환 시 추억 정령 (공용 유닛, 강화)
 3단계  ★ 강아지 (영웅)    → 소환 시 강아지 영웅 (고유 유닛, 고유 스킬)
```
- 조각에는 **종류(추억 체인)**와 **단계**가 있다. 같은 종류 + 같은 단계끼리만 합쳐진다.
- 1~2단계는 **공용 유닛**(추억 정령)으로 소환, 3단계만 **고유 영웅**으로 소환 → 아트 비용을 영웅에 집중.

### 통로에 따른 영웅의 두 모습
- Happy에게 보내면: 함께 뛰어놀던 모습으로 걱정을 막는다 (따뜻한 팔레트).
- Unhappy에게 보내면: 곁을 지켜주는 모습으로 심연을 앞장선다 (차가운 팔레트).
- 스프라이트 1개 + 팔레트 스왑으로 구현.

### 챕터(나이)별 추억 체인 (예시)
| 챕터 | 추억 체인 (영웅) |
|---|---|
| 5살 | 강아지, 담요 인형, 할머니 |
| 8살 | 단짝 친구, 자전거, 선생님 |
| 12살 | (추후 결정) |

### 두 세계와의 연결
- 음에서 정화한 기억은 **그 기억에 해당하는 체인의 조각**으로 그리드에 돌아온다. (예: "혼자 남은 운동장" 정화 → 단짝 친구 체인 조각)
- 영웅을 처음 소환하면 **추억 도감**에 기록 → 수집 동기. 엔딩 크레딧에 "이 아이를 지켜준 추억들"로 표시 (안).

### 리스크와 대응
| 리스크 | 내용 | 대응 |
|---|---|---|
| **그리드 막힘 (가장 큼)** | 종류가 생기면 "같은 종류 + 같은 단계"여야 합쳐져 3×3은 금방 막힌다 | ① 그리드 **4×4 이상** ② 한 챕터에 등장하는 체인 **2~3개로 제한** ③ 어떤 조각과도 합쳐지는 **와일드카드 조각**(예: "햇살", 정화 보상 등으로 획득) ④ 막힘 해소 수단: 조각을 기쁨으로 되돌리는 "놓아주기"(소량 환급) |
| 영웅 아트 비용 | 영웅마다 고유 스프라이트·애니메이션·스킬 필요 | 챕터당 영웅 **3~4명**, 전체 **15~20명 이내**. 1~2단계는 공용 유닛 재사용, 위/아래는 팔레트 스왑. 프로토타입은 **영웅 2명** |
| 소재 수위 | 강아지·할머니 체인은 결국 "이별"로 이어질 수 있다 | 이별은 **음의 세계에서 상징적으로만** 다룬다 (예: 멀어지는 발자국, 빈 의자). 죽음을 직접 묘사하지 않는다. 수위 기준 문서에서 확정 |
| 밸런스 복잡도 | 영웅 고유 스킬이 들어가면 조합 밸런스가 복잡해진다 | 프로토타입은 **스킬 없이 스탯 차이만**. 스킬은 재미 검증 후 1인당 1개로 추가. 모든 수치는 JSON |
| 체인 편중 | 특정 체인만 키우는 것이 최적이 될 수 있다 | 조각 생성 시 체인별 등장 확률을 JSON으로 조정. metrics로 체인별 소환 횟수 기록 |

### 프로토타입 범위 (이 섹션 기준)
- 그리드 4×4, 추억 체인 2개(예: 강아지, 담요 인형), 각 3단계
- 영웅 2명(각 체인의 3단계), 1~2단계는 공용 유닛, 스킬 없음
- 와일드카드 조각 1종, "놓아주기" 1종
- 검증: 체인이 생기면서 "무엇을 합치고 언제 보낼지" 고민이 더 재미있어지는가 / 그리드 막힘이 전략으로 느껴지는가, 짜증으로 느껴지는가

| 위치·이동 | 레인 아래쪽(그리드 바로 위) 방어선에 정지 | Unhappy 뒤에서 거울 속(화면 위쪽)으로 전진 |
| 전투 | 내려오는 걱정을 자동 공격 | 그림자 벽(층)을 자동 공격 |
| 수명 | 체력제. 걱정에 닿으면 체력 감소, 0이면 소멸 | 체력제. 그림자의 반격으로 체력 감소 |
| 성공 | 걱정 처치 → **즉시 기쁨** | 층 돌파 → **정화 완료** → 유닛이 빛 조각이 되어 **단계 +1로 그리드에 귀환** |
| 실패 | 쓰러지면 소멸 (페널티 없음) | 쓰러지면 조각 소실 + 그림자 증가 (위험 부담) |
| 하루 끝 | 살아남은 유닛은 **단계 그대로 그리드로 귀환** (D-022) | 살아남은 유닛은 단계 그대로 귀환 |
| 정원 | 레인당 최대 N기 (프로토타입 5기, JSON) | 레인당 최대 N기 (프로토타입 5기, JSON) |

### 세부 규칙
- **3단계 영웅의 정화 성공:** 더 올라갈 단계가 없으므로 **와일드카드 조각 1개 + 추억 도감 진척**으로 보상.
- **Happy:** 방어선 중앙의 **쓰러지지 않는 거점**. 몬스터가 방어선을 통과하면 거울 너머(음의 세계)로 가라앉는다.
- **Unhappy:** **혼자서는 전진하지 못한다.** Unhappy에게 보낸 추억이 없으면 제자리에 멈추고 그림자가 쌓인다 = "외면"의 정의. ("아무도 도와주지 않으면 Unhappy는 멈춘다")
- **단계별 체력·공격력:** JSON으로 분리, 플레이하며 조정.

### 선택의 긴장
- Happy에게 보내기: 확실하고 빠르다. 쓰러지면 사라지고, 버티면 그대로 돌아온다 (성장은 없음).
- Unhappy에게 보내기: 느리고 위험하지만, 성공하면 더 강해져서 돌아온다. (= "지연되지만 더 큰 보상" 원칙의 구체 규칙)

### 퇴화 전략 방지 (자기 균형 루프)
- Unhappy에게만 보내면 → Happy 쪽이 비어 걱정이 가라앉음 → 심연의 그림자가 강해짐 → Unhappy 쪽도 어려워짐.
- Happy에게만 보내면 → Unhappy가 멈춤 → 그림자 누적 → 역류.
- 어느 한쪽만 고집하면 스스로 불리해진다. 실제 균형은 프로토타입 metrics로 확인.

### 제품 목표와의 관계
- 이 규칙은 F2P / 완결형 어느 쪽이든 공통. 제품 목표에 따라 달라지는 것은 **오프라인 중 레인 진행 여부**뿐.

## 하루 구조 (2026-09-30 확정)

> 메시지: **평범한 하루도 소중하다.** 하루하루를 살며 얻는 행복과 불행이 마음에 들어온다.

### 하루 = 한 판
```
[오늘: 8살 봄, 평범한 화요일]
 아침 ─ 낮 ─ 저녁  (웨이브 3개, 한 판 3~5분)
   │
   ├─ 오늘의 이벤트가 결정하는 것
   │    · 그리드에 들어오는 조각 (행복한 일 → 해당 추억 체인 조각 증가)
   │    · 몰려오는 걱정 (속상한 일 → 걱정 웨이브 강화)
   │
   ├─ 해질녘: 지키던 추억은 그리드로 돌아와 쉬고, 맡겨둔 추억은 꿈속으로 (D-027)
   ├─ 밤: 꿈속 심연에서 그림자 벽 정화 (달이 질 때까지)
   └─ 새벽: 추억들이 돌아온다 → 그림일기 한 줄 → 일기장(추억 도감)에 누적
        "오늘은 이가 빠졌다. 조금 아팠지만 베개 밑에 넣고 잤다."
```

### 이벤트 체계
| 종류 | 예시 | 성격 |
|---|---|---|
| 인생의 이정표 (고정) | 처음 이를 뽑는 날, 입학, 첫사랑, 전학 | 나이별 1회의 큰 사건. **Happy/Unhappy 중 누가 맡을지 선택은 이정표에서만** 등장 |
| 계절 이벤트 (매년 반복) | 크리스마스, 생일, 여름방학, 첫눈 | 해마다 오지만 나이에 따라 연출이 달라짐 |
| 일상 이벤트 (랜덤) | 넘어져 다친 날, 급식에 좋아하는 반찬, 비 오는 날 | 작은 행복·작은 불행 |
| 평범한 하루 | 아무 일도 없는 날 | 날씨·요일·작은 변주 (예: 창밖의 무지개) |

- 하루 생성 방식: **하루 템플릿 + 이벤트 풀 조합** (1인 개발 콘텐츠 비용 통제). 이정표만 직접 집필, 나머지는 조합.
- 이벤트·일기 문장은 모두 데이터(JSON)로 분리.

### 그림일기
- 이벤트 + 그날의 결과(막아낸 걱정, 정화한 기억 등)를 조합해 한 줄 자동 생성.
- 일기장에 누적 → "이 아이의 일생" 기록. 엔딩에서 일기장을 넘겨보는 연출로 회수 (안).

### 하루 진행 방식: C안 (확정)
- **하루에 열 수 있는 날 수 제한 + 밀린 날은 일정 일수까지 보관.**
- 매일 접속할 이유를 주면서, 몰아서 하는 플레이도 어느 정도 허용.
- 접속하지 않은 날: 벌칙 없음. 보관 한도를 넘은 날은 **"기억나지 않는 날"**로 조용히 지나간다 (따뜻한 톤 유지).
- 버린 안: A. 실제 하루 = 게임 하루 (몰아하기 플레이어 이탈) / B. 판마다 하루 경과 (매일 접속 동기 약함)

### 규모 (설계 목표값, 확정 아님)
- 일생 = 플레이 약 120일 (예: 5살 ~ 어른, 나이당 10~15일)
- 이정표 이벤트 15개 안팎, 계절 이벤트 8~10종, 일상 이벤트 풀 30~40개, 나머지는 평범한 하루

### 리스크
| 리스크 | 대응 |
|---|---|
| 콘텐츠 양 (가장 큼) | 템플릿 + 이벤트 풀 조합. 이정표만 수작업 |
| 평범한 하루의 지루함 | 작은 변주 + 핵심 루프(머지·소환) 자체의 재미. 프로토타입 검증 대상 |

## 톤 가이드 (따뜻한 동화)
- 게임 전체는 따뜻하고 다정하다. 불행을 무섭게 그리지 않는다.
- 불행한 기억·몬스터는 "물리칠 적"이 아니라 "돌봐주고 안아줄 존재"로 표현한다. 정화 = 위로.
- 역류·가짜 엔딩의 긴장감은 공포가 아니라 쓸쓸함으로 전달한다.
- 가장 나쁜 결말에도 희망을 남긴다.
- 한 줄 요약: "불행을 없는 척하지 않고, 따뜻하게 안아주는 동화."

## 핵심 전제
- 무대는 한 아이의 마음속이다. 아이는 챕터(나이)마다 자란다 (예: 5살 → 8살 → 12살 → ... → 어른).
- 양의 세계(의식): 행복한 기억이 모인 곳. 일상의 걱정이 몬스터가 되어 몰려오고, Happy와 Happy에게 보낸 추억들이 막는다.
- 음의 세계(무의식): 막지 못한 상처와 오래된 불행한 기억이 가라앉은 심연. Unhappy와 Unhappy에게 보낸 추억들이 거울 속 깊이 들어가 그림자를 뚫고 정화한다.
- 메시지: 행복은 불행을 지워서가 아니라 소화해서 지켜진다.

## 캐릭터
- 아이: 마음의 주인. 플레이어가 직접 조작하지 않는다. Happy·Unhappy의 상태에 따라 반응하고 자란다.
- Happy: 양의 세계를 지키는 수호자 (모두가 원하는 모습)
- Unhappy: 음의 세계로 내려가 정화하는 탐험자 (아무도 원하지 않지만 실제로 고된 일을 하는 쪽). 악역이 아님.
- 엔딩: 둘은 아이의 두 면. "Happy가 웃을 수 있었던 건 Unhappy 덕분" → 제목의 And에 의미.
- (안) Happy·Unhappy를 동물형 캐릭터로 디자인 → 귀여움 확보 + 인사이드 아웃과 시각적 차별화.

## 성장치 정의 (안) — 결말 판정의 입력값
- Happy 성장치: Happy에게 보낸 추억(등급 합) + 방어한 웨이브 수 + 누적 기쁨
- Unhappy 성장치: Unhappy에게 보낸 추억(등급 합) + 정화한 기억 수 + 도달한 심연 층 + 해소한 그림자량
- 설계 의도: Happy에게 보내면 효과가 즉시 보이므로 플레이어는 자연스럽게 Happy 쪽으로 쏠림 → 기본값이 "웃는 가면" 쪽으로 기울어짐 = 게임의 역설을 시스템으로 구현.
- 단, Unhappy에게 보낸 보상이 확실히 돌아와야 함 (지연되지만 더 큰 보상). 그렇지 않으면 "Unhappy에게 보내기"는 손해로만 느껴짐.

|---|---|---|---|
| 강 | 약 | 웃는 가면의 어른 | 가짜 행복 엔딩. 늘 웃지만 공허 |
| 약 | 강 | 조용한 어른 | 아픔을 알지만 웃는 법을 잊음 |

## 난이도 원칙 (D-020)
- **게임 오버는 없다.** 막지 못한 걱정은 가라앉고, 그림자가 쌓이고, 역류가 온다. 난이도는 실패 화면이 아니라 **결말의 질**로 드러난다.
- **첫 일생에서 최선의 결말은 쉽게 나오지 않는다.** 보통 첫 회차는 "웃는 가면"이나 "비 오는 어른". 다음 세계(회차)를 거치며 "단단한 어른"·히든에 도달한다.
- 초반은 쉽게, 이정표·역류에서 긴장이 오른다. 한쪽만 고집하는 전략은 최선의 결말에 닿지 못한다.
- 밸런스는 자동 플레이 시뮬레이터로 조정하고 사람 플레이로 보정한다 (스펙 §8.1, §8.2).

## 타이틀 연출
핵심: **Unhappy라는 단어 안에 Happy가 들어 있다.** 로고에서 암시하고, 엔딩에서 회수한다.

### 1. 거울 반사 로고 (타이틀 화면)
- 플레이 화면의 거울 구조를 로고에 그대로 적용 (D-017로 수면 → 거울 변경).
- 거울 앞: "HAPPY" (따뜻한 팔레트) / 거울에 비친 모습: "UNHAPPY" (차가운 팔레트).
- 의미: Happy를 거울에 비추면 Unhappy가 된다 = 둘은 같은 존재. 첫 화면부터 엔딩의 반전을 암시.

### 2. 결말별 엔딩 제목
엔딩 크레딧의 제목이 아이가 어떤 어른이 되었는지를 보여준다. 설명 없이 제목만으로 메시지 전달.

| 결말 | 엔딩 제목 |
|---|---|
| 웃는 가면의 어른 | **Happy** — Unhappy 글자가 사라진 제목. 완벽하지만 비어 있음 |
| 조용한 어른 | **Unhappy** |
| 비 오는 어른 | **Happy And Unhappy** — 글자가 빗물에 번짐 |
| 단단한 어른 | **Happy And Unhappy** — 그대로. And에만 빛이 들어옴 |
| (히든) 화해 | Unhappy 안의 "happy"와 Happy가 겹쳐 **(Un)Happy** 하나가 됨. 마지막 대사: "불행 속에도 행복이 들어 있었어." |

### 현지화 주의
- 이 말장난은 영어에서만 성립 (한국어 "행복/불행"은 글자를 공유하지 않음).
- 방침(안): 로고는 전 세계 공통 영어 "Happy And Unhappy" 유지, 반전은 시각 연출로 전달.
- 필요 시 한국어판 부제 별도 (예: "해피 앤 언해피: 마음의 거울").

## 인생 이벤트 (이정표 이벤트의 선택 규칙)
- "하루 구조"의 **이정표 이벤트**에서 발생 (처음 이를 뽑는 날, 친구와 싸운 날, 전학, 동생이 태어남 ...).
- 플레이어는 아이 대신 선택하는 게 아니라 **그 일을 Happy와 Unhappy 중 누가 맡을지** 정한다.
  - Happy가 맡음(웃어넘김 = 회피): 기쁨 +, 그림자 누적
  - Unhappy가 맡음(마주함 = 직면): 기쁨 −, 음의 세계에 정화 가능한 기억 생성
- 분기는 트리가 아니라 누적 변수. 이벤트·수치는 JSON 데이터로 분리.

## 두 세계의 연결
| 방향 | 시스템 | 세계관 해석 |
|---|---|---|
| 양 → 음 | 방어 레인에서 놓친 몬스터가 음의 세계에 가라앉아 심연 레인의 강한 그림자가 된다 | 제때 다루지 못한 스트레스가 상처로 남는다 |
| 음 → 양 | 정화에 성공하면 더 높은 등급의 조각이 머지 그리드로 돌아온다 | 극복한 아픔이 마음을 단단하게 만든다 |
| 음 방치 → 양 | Unhappy에게 보내지 않으면 그림자 누적 → 역류 보스 웨이브 | 외면한 감정은 더 크게 돌아온다 |
| 전역 | 마음 날씨(맑음 ~ 폭우) 게이지 | 전체 기분 상태 |

## 콘텐츠 축
- 양의 세계 웨이브: 아이의 일상 걱정 (받아쓰기 시험, 주사 맞는 날, 발표 시간, 편식 반찬)
- 음의 세계 스테이지: 상징적 기억 장면 (놓쳐버린 풍선, 혼자 남은 운동장, 동생에게 뺏긴 자리, 함께 자란 강아지와의 이별)
- 몬스터: 의인화한 감정(불안, 후회, 질투, 외로움 ...) — 귀엽고 안쓰러운 모습
- 재화: 기쁨(양), 그림자 조각(음), 정화된 기억(결합 재화 = 해당 추억 체인의 머지 조각)
- 추억 체인·영웅: 챕터별 2~3개 체인, 체인 정점이 영웅 ("추억 체인과 영웅 소환" 섹션)
- 소재 수위: 학대·이혼·죽음 등 무거운 주제는 제외하거나 상징적으로만 다룬다 (기준 확정 필요).
- 타깃: 아이가 주인공이지만 아이용 게임이 아님. 성인 대상.

## BM 원칙
- 정화 가속·역류 방지·성장 가속 판매 금지 ("아이의 슬픔/성장을 돈으로 산다" 인상 방지).
- 코스메틱 중심 (Happy·Unhappy 스킨, 마음 정원 꾸미기 등).

## 모바일·도트 화면 아이디어
- 세로 화면을 가운데 거울로 좌우 분할: 왼쪽 = 양의 세계(방어 레인), 오른쪽 = 거울에 비친 음의 세계(심연 레인), 하단 = 머지 그리드 (D-017).
- (구) 수면 위/아래 분할안은 D-017에서 대체.
- 팔레트 스왑: 양(따뜻·밝음) / 음(차갑·채도 낮음). 마음 날씨도 팔레트 변화로 표현.

## 차별화 메모
- 아이의 마음 + 의인화 감정 → 인사이드 아웃과 겹칠 위험 큼. 차별점: 두 세계 공간 구조 + 억압/역류 시스템, 주인공은 감정이 아니라 두 개의 자아, 한 시기가 아닌 어른이 되기까지의 긴 성장, 결말이 "어떤 어른이 되는가".

## 미정 / 미해결
- 회차 구조: 방향은 "일생을 마치면 다음 세계가 열림"(D-016). 이어받는 요소(도감·해금 등)는 미정
- 두 번째 세계 선정 (가상 세계 중)
- (해결) 제품 목표 → "매일 하루를 사는 완결형 일생 게임" (D-014). 레인 전투는 하루 단위 판으로 진행, 오프라인 방치 진행 없음
- 하루 진행 C안 세부: 하루에 열 수 있는 날 수, 밀린 날 보관 한도
- BM 형태: 코스메틱 F2P vs 유료 판매
- 그리드 크기: 4×4 / 5×4 / 6×4 프로토타입 비교 후 확정 (결정 기록 D-012)
- 한 회차 길이: 목표값 플레이 약 120일 (나이당 10~15일) — 프로토타입 후 확정
- 이벤트 목록 작성: 이정표·계절·일상 이벤트 풀, 그림일기 문장 규칙
- 성장치 정의·결말 판정 임계값 확정
- 추억 체인 세부: 12살 이후 체인, 영웅 고유 스킬, 와일드카드 획득 경로, 추억 도감의 보상 여부
- 소재 수위 기준 문서 (이별·죽음 표현 범위)
