# 1권 1챕터 — 해와 달이 된 오누이 (초안, 2026-10-01)

> 원전: 한국 설화 "해와 달이 된 오누이" (퍼블릭 도메인). 원전만 참고해 다시 씀. 현대 그림책·각색본의 문장·삽화는 쓰지 않는다.
> 기준: `00-current-design.md`, 소재 기준 `content-guidelines.md`, 결정 D-032·D-038·D-040. 1권 = 동양 설화.

## 교훈 (한 줄)
**"함께라면 어떤 어둠도 건널 수 있다."** — 설교하지 않고 플레이로 보여준다: 낮의 해(Happy)와 밤의 달(Unhappy)이 서로를 받쳐야 챕터가 끝난다.

## 원전에서 부드럽게 바꾸는 것 (D-031)
| 원전 | 바꿈 |
|---|---|
| 호랑이가 엄마를 잡아먹음 | 엄마는 고개에서 **길을 잃는다**. 마지막에 해와 달이 된 오누이가 엄마의 길을 비춰 집으로 돌아온다 |
| 호랑이가 수수밭에 떨어져 죽음 | 떨어지는 호랑이를 **달이 받아 안아준다**. 수수밭의 붉은빛은 호랑이의 외로움이 노을이 된 것 |
| 도끼로 나무를 찍음 | 호랑이가 발톱으로 미끄러지며 기어오름 (우스꽝스럽게) |

## 장면 (낮 = 해의 면 배경 / 밤 = 달의 면 층)
| 스테이지 | 낮 배경 (지키는 곳) | 밤 층 (내려가는 곳) |
|---|---|---|
| 1-1 | 떡을 찌는 아침 부엌 | 첫째 고개의 어둠 |
| 1-2 | 떡 광주리를 이고 나서는 길 | 둘째 고개 — "떡 하나 주면 보내주지" 목소리 |
| 1-3 | 고갯마루의 들꽃 | 셋째 고개 — 길을 잃은 엄마의 발자국 |
| 1-4 | 엄마를 기다리는 오두막 | 해가 진 뒤의 숲 |
| **1-5 전환점** | 문 앞의 등불 | **엄마 목소리를 흉내 내는 문틈의 털복숭이 손** (조금 강한 층 + 특별 페이지) |
| 1-6 | 뒷문 밖 장독대 | 오누이를 쫓는 발자국 소리 |
| 1-7 | 우물가 큰 나무 | 나무를 기어오르다 미끄러지는 그림자 |
| 1-8 | 나뭇가지 위 오누이 | 나무 아래를 맴도는 줄무늬 그림자 |
| 1-9 | 하늘에서 내려온 튼튼한 동아줄 | 썩은 동아줄의 냄새 |
| **1-10 보스** | 하늘로 오르는 오누이 | **호랑이** — 정화하면 달이 안아주고, 오누이는 해와 달이 된다 → **챕터 완성** |

## 낮의 적 (호랑이가 보낸 것들, 귀엽지만 유치하지 않게)
| 이름 (안) | 성격 | 등장 |
|---|---|---|
| 줄무늬 그림자 | 기본, 느림 | 1-1~ |
| 덤불 살쾡이 | 빠르고 약함 | 1-3~ |
| 털장갑 손 | 단단함 (1-5 전환점 이후) | 1-5~ |

## 체인 (머지 조각 → 영웅) — 프로토타입 체인 2개에 대응
| 프로토타입 키 | 1단계 | 2단계 | 3단계 영웅 |
|---|---|---|---|
| `companion_animal` | 떡 한 조각 | 떡 광주리 | **떡 할미** (버티는 형) |
| `comfort_object` | 지푸라기 | 새끼줄 | **하늘 동아줄** (공격형) |

## 전설 (조합표 5개 이름 안)
| id | 종류 | 이름 (안) |
|---|---|---|
| `sunny_picnic` | 행복 | 해를 닮은 떡 |
| `nap_friend` | 행복 | 오두막의 등불 |
| `not_alone_night` | 정화 | 함께 오른 동아줄 |
| `park_walk` | 정화 | 줄무늬 노을 |
| `cozy_nap` | 정화 | 달빛 장독대 |

## 길잡이 (보류, D-041)
- 후보: **토끼** — 달에 사는 토끼. 밤마다 Unhappy(달)에게 길을 알려준다. 길잡이 시스템 자체를 쓸지는 미정.
