# 참고 게임 — 머지형 · 조합법 (2026-10-01)

> 목적: M8.10(동료·덱, D-047) 설계 참고. 기사·위키·공식 공지 기준이며 **직접 플레이로 확인한 것이 아니다.** 수치는 각 게임 현재 버전과 다를 수 있다.

## 1. 한눈에
| 게임 | 머지 규칙 | 조합법·시너지 | 우리에게 쓸 것 |
|---|---|---|---|
| Travel Town · Gossip Harbor (머지-2) | 같은 것 2개 → 다음 단계. 생성기에 에너지를 써서 조각 획득 | **주문(order)**: 특정 단계 물건을 요구 → 진행 | 머지를 중심에 두고 나머지를 덜어냄. 주문 = 조합법 카드 표시 방식 |
| 랜덤 다이스 (111%) | 같은 종류·같은 눈 2개 → **종류 랜덤** + 눈 1. 소환 비용이 소환마다 +10 | **덱 = 주사위 5종을 판 전에 고름.** 판 안에서 SP로 **종류별 파워업**, 판 밖 클래스 업그레이드 | 덱 = 판 전에 체인 고르기. 먹이기를 "종류(체인) 파워업"으로 보는 해석 |
| 운빨존많겜 (111%) | 같은 영웅 3개 → 상위 등급 | **신화 = 정해진 영웅 조합으로만.** 대부분 제거 불가(신중한 선택). 판 밖 신화 레벨업 | 조합법 결과 = 판 안에서 되돌릴 수 없는 결정. 판 밖 성장(본 개발) |
| 원피스 랜덤 디펜스 (War3 유즈맵) | 랜덤 위습 → 무작위 유닛 | **조합표**로 기본 유닛 → 상위 유닛. 10라운드마다 보스, 시작 시 특성(항법) 선택 | 우리 구조(10층 보스·조합표)의 원형. 조합표를 늘 보이게 하는 이유 |
| Merge Tactics (Clash Royale, 2025) | 같은 유닛 2개 → 별 +1 (최대 3~4성) | **유닛마다 특성 2개**, 같은 특성 2·4기에서 보너스. 상점 3장, 팔면 비용 −1 환불 | 동료 7종으로 시너지를 만들려면 **태그 2개** 방식이 효율적 |
| Super Auto Pets | 같은 펫 3마리 → Lv2, 6마리 → Lv3 | 레벨업하면 **다음 등급 펫을 상점에 하나 줌** (머지에 능력치 외 보상) | 3단계 머지 순간의 추가 보상 |
| Backpack Battles (2025 정식) | 인접한 물건끼리 **조합법으로 합쳐짐** | 배치(인접)가 효과를 바꿈. 일부 조합은 촉매(소모 안 됨)가 필요 | 그리드 위치가 의미를 갖는 방식 — 지금 단계에선 과함 |
| 스톤에이지 키우기 (넷마블, 2026) | — (뽑기·레벨·별) | 조련사 1 + 펫 3 = 팀, 역할·속성 상성, 낮은 등급도 조합으로 활용 | D-047 방향의 원본 |

## 2. 배울 점 → Happy And Unhappy 적용 (안)
1. **머지를 중심에 두고 시스템 수를 묶는다** (Travel Town). 현재 판 안 시스템: 머지 · 먹이기 · 전투 중 버프 · 동료 · 조합법 · 시너지 · 등급 — 이미 많다. M8.10은 **동료 + 조합법 + 시너지 1종**까지만, 등급은 본 개발.
2. **덱 = 판 전에 체인을 고른다** (랜덤 다이스). 프로토타입은 체인 2개 고정, 본 개발에서 4~6개 중 고르기(D-043과 일치).
3. **먹이기의 단위를 다시 본다** (랜덤 다이스 종류별 파워업). 후보:
   - (가) 지금처럼 **영웅·동료 개별** 강화 — 고를 게 많고 UI가 복잡
   - (나) **체인 단위** 강화 — 떡을 먹이면 "떡 계열 동료 전부"가 강해짐. 결정이 단순하고 D-043 "전설 = 체인 강화 재료"와 같다. 대신 "누이 vs 오라비 배분" 긴장은 동료 배치로 옮겨감.
4. **동료마다 태그 2개 + 2기 시너지** (Merge Tactics). 태그 = 체인(떡/동아줄) + 역할(탱커/근접/원거리/서포트). 같은 태그 2기면 보너스 → 동료 7종만으로도 조합 경우의 수가 생김.
5. **조합법 = 주문 카드처럼 늘 보이게** (Travel Town 주문 + 운빨존많겜 조합 안내). 그리드에 재료가 모이면 카드에 "만들 수 있음" 표시, 진행 칸(1/2) 표시.
6. **조합 결과는 판 안에서 되돌리지 않는다** (운빨존많겜 신화 제거 불가). 동료로 앉히면 그 판 내내 — 결정에 무게. 교체는 빈 칸에만.
7. **3단계 머지 순간의 보상** (Super Auto Pets). 이미 전투 중 버프 ×2가 있음. 추가로 "3단계 완성 시 다음 조각 1개 무료" 같은 것은 시뮬로 효과 보고 결정.
8. **소환 비용 증가로 페이스 조절** (랜덤 다이스 +10). 이미 `spawnCostStep`가 같은 역할 — 유지.

## 3. 가져오지 않을 것
- 뽑기·확률형 획득 (랜덤 다이스·운빨존많겜·스톤에이지): 머지가 그 자리 (D-047). 운빨존많겜은 확률 조작 의혹이 비판점으로 남아 있다.
- 에너지 과금 구조 (머지-2): 우리 gating(C안)과 BM은 별도 결정.
- 인접 조합 (Backpack Battles): 그리드 규칙이 바뀌는 큰 변경 — 본 개발 후보로만 기록.
