# Happy And Unhappy — 현재 기획 한 장 정리 (2026-10-01)

> **이 문서가 기준이다.** 흩어진 결정(D-001~D-035)을 지금 시점으로 정리했다. 세부 규칙은 스펙(`02-spec/prototype-spec.md`), 근거는 결정 기록(`03-decisions/decision-log.md`).
> 문서 사이에 충돌이 있으면 이 문서 → 결정 기록 → 스펙 순으로 따른다. 이 문서는 결정이 바뀔 때마다 고친다.

## 1. 한 문장
**우리는 옛이야기(설화)를 여행한다.** 길동무는 **해(Happy)**와 **달(Unhappy)**. 낮에는 해가 비추는 동안 이야기의 어두운 곳으로 내려가 두려움을 안아주고(정화), 밤에는 달 아래에서 몰려오는 악당의 무리로부터 이야기의 집을 지킨다. 독자인 우리는 두 영웅 오누이와 함께 시작해 낮덱·밤덱을 꾸리고, 그 이야기의 물건을 합쳐 영웅을 키우고, 1-10 보스를 정화할 때마다 챕터가 완성된다. 10챕터를 다 채우면 **옛이야기 책 한 권**이 완성된다 — 그것이 결말이고, 다음 책(다른 문화권의 신화)이 열린다.

## 2. 지금 확정된 것

### 2-1. 핵심 루프 (프로토타입에서 검증 중)
| 요소 | 규칙 | 결정 |
|---|---|---|
| 조작 | 머지 그리드 하나만 직접 조작, 전투는 자동 | D-010 |
| 스테이지 | **1-n = 낮 한 번 + 밤 한 번.** 낮(오펜스): 핵을 쥔 그림자를 쓰러뜨려 **동화의 핵**을 찾고 **오두막까지 가지고 돌아옴**(추격·떨어뜨림). 밤(디펜스): 오두막의 핵을 지킴(핵 HP). 둘 다 성공 → 아침 이야기 한 장 → 다음 스테이지 / 낮 실패 → 밤 없이 낮 다시, 밤 실패 → 낮부터 다시 | D-027, D-046, D-053 |
| 덱 | **조련사 없음. 플레이어 = 독자.** 오누이 = 처음 주는 영웅 두 명, 낮덱/밤덱 배치는 플레이어 선택(양쪽 최소 1명, 한쪽에 넣으면 다른 쪽 불가). **독자 레벨 ↑ → 배치 칸 양쪽 +1.** 덱 = 배치(진형 2×3/3×2, 탱커·공격형 구성). **덱을 바꾸면 지금 단계가 처음부터 다시** | D-045, D-046, D-049 |
| 머지 단계 | **1~5단계.** 합칠 때마다 병사(1~4단) + 버프, 조각은 기운 재료(1/3/7/15/**50**). **5단계 = 가장 큰 기운 조각 + 특별 버프**(해 "한낮" / 달 "보름달"). 5단계는 더 못 합침 | D-052 |
| 머지 조각 → 영웅 성장 | 조각을 영웅에게 먹이면: **해 체인(떡) → SP = 레벨 → 능력치**, **달 체인(동아줄) → AP = 성급(1~5★) → 스킬 강화**. 영웅마다 자동 스킬 1개. 먹이면 소모 → 누구에게 줄지가 선택 | D-045, D-051 |
| 전투 중 머지 | 싸우는 동안 머지하면 **병사가 자동 출전**(일회성, 떡 방패병 / 동아줄 올가미병) + **지금 싸우는 덱 버프**(떡 회복 / 동아줄 기세). **때 맞춤:** 낮에 해 체인·밤에 달 체인 = ×1.5. 결과 조각은 남아 강화 재료 | D-045, D-050 |
| 이야기 진행 | 스테이지마다 여는 글 · 동화의 핵 · 이야기 한 장 (1챕터 문구: `stories/ch01-sun-and-moon.md`). 1-5 중간 보스 → 갈림길, 1-10 보스 → 챕터 완성(누이 = 해, 오라비 = 달) | D-053 |
| 조합법 · 영웅 | 새 영웅은 **조합법으로만** 획득 → 도감·등급. 체인 = 역할, 조합 = 시너지 (스톤에이지 키우기 참고, 방치·뽑기 제외). M8.9는 제작 끔, M8.10에서 설계 | D-047, D-049, D-052 |
| 보스 층 | 심연 10층마다. 돌파 시 와일드카드 | D-029 |
| 챕터 완성 보상 | 1-10 정화 → **해의 조합법 + 달의 조합법** (오누이 / 정화된 호랑이). 체인은 책마다 4~6개, 덱은 그중 4개 (프로토타입은 문구만) | D-042, D-043 |
| 결말 | **하나: 동화책의 완성** (10챕터). 프로토타입은 1-10 핵을 가져오면 끝. 좋은/나쁜 결말 없음.  | D-037 |
| 이벤트·이정표 | 일상 이벤트 → 그날의 이야기 장면 효과, 이정표 → 동화 속 갈림길 선택 (효과 규칙 그대로) | D-039 |
| 진행 제한 | **없음.** 일차·하루 열림(C안)·20일 제한 삭제. 무제한 재도전, 실패해도 성장은 남음. 막히는 건 난이도뿐 | D-054 (D-015 대체) |
| 톤 | 따뜻한 동화. 걱정은 "안아줄 존재" | D-004 |
| 틀 | **우리가 옛이야기(설화)를 여행한다. 해·달은 두 길동무.** 낮 = 밝은 장면을 악당의 무리로부터 지킴, 밤 = 어두운 곳에서 두려움을 정화. 머지 조각 = 그 동화의 물건·동료. 주제 = 각 동화의 교훈 + "모든 이야기엔 두 면이 있다". "어른이 다시 펼친 책"은 프롤로그·표지로만 | D-036, D-038, D-039 |

### 2-2. 이야기·소재 (본 개발 방향, 프로토타입엔 이름·연출만)
| 요소 | 내용 | 결정 |
|---|---|---|
| 책 | **책 한 권 = 10챕터, 권 순서 = 난이도.** 1권 설화(민담) → 2권 동양 신화(사신수·사흉수) → 그리스·로마·북유럽·이집트 신화. 다 채우면 다음 책. 모드 분리 없음 | D-040, D-041 |
| 챕터 | 설화 한 편 = **1-1 ~ 1-10** (1-5 전환점, 1-10 보스 = 그 이야기의 두려움 → 정화하면 챕터 완성) | D-032, D-033, D-035 |
| 1챕터 | **해와 달이 된 오누이** — 교훈 "함께라면 어떤 어둠도 건널 수 있다". 초안 `01-planning/stories/ch01-sun-and-moon.md` | D-032, D-038 |
| 설화 | 원전(퍼블릭 도메인)만 참고해 다시 씀. 현대 각색물(마블 등) 디자인 금지, 지금도 믿는 종교의 신은 다루지 않음. 화면 용어 "옛이야기" | D-032, D-040 |
| 이야기 한 장 | 하루 끝 기록 = 그날 헤쳐 나간 이야기 장면 한 페이지 (구 그림일기·그림동화) | D-033, D-038, D-040 |
| 옛이야기 책 한 권 | **10챕터를 다 채우면 책이 완성 = 결말**, 다음 책이 열림 | D-035, D-037, D-040 |
| 신화 소재 | 사신수 = 해의 면 수호자, 사흉수 = 달의 면 깊은 두려움(보스) — **2권** | D-038, D-041 |
| 소재 기준 | **현대사·실제 역사적 사건은 다루지 않는다.** 무거운 개인사는 상징적으로, 점수가 아니라 이정표·그림동화에서 | D-031 |
| 제품 방향 | **A: 이야기 연속 + 결말. 방치형 없음** | D-034 |
| BM 원칙 | 성장·정화를 돈으로 팔지 않는다, 코스메틱 중심 | 세계관 |
| 기술 | 프로토타입 Phaser(버리는 코드) → 본 개발 Godot. 넘기는 것은 규칙 + JSON 수치 | D-003 |
